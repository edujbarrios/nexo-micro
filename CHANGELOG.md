# Changelog

All notable user-visible changes will be documented here. Follow [SemVer](https://semver.org/).

## [0.1.0] - 2026-10-15

Initial experimental release candidate:
- Micro/1 strict base36 semantic event grammar and deterministic macro dictionary fingerprint.
- Host-only `Hello` negotiation, `Frame` sequence checks and isolated duplex task state.
- Tokenizer-aware per-message fallback to compact JSON; optional tiktoken benchmarks.
- Reference examples, tests, CI, MIT license and PyPI Trusted Publishing workflow.

**Limits:** not universal natural-language compression, not encryption, not authenticated transport,
not a trained natural-language model and not proof of total API billing savings.
